## 🚀 איך פותחים את האתר

### בדיקה מקומית מהירה
פתח את `index.html` ישירות בדפדפן.

> **שים לב**: פעולות auth (כניסה/הרשמה) דורשות חיבור לאינטרנט כי הן עובדות מול Supabase.

### העלאה ל-Netlify (מומלץ - חינמי)
1. גש ל-https://app.netlify.com והירשם
2. לחץ "Add new site" → "Deploy manually"
3. גרור את **תיקיית הפרויקט כולה** לאזור ה-Deploy
4. תקבל כתובת: `shidduchim-xxx.netlify.app`
5. עדכן ב-Supabase: Authentication → Settings → Site URL → הכנס את כתובת Netlify

## 🔧 הגדרות Supabase שצריך לבדוק

### 1. הרצת ה-SQL (חובה!)
אם עדיין לא הרצת:
1. Supabase → **SQL Editor** → New query
2. העתק את כל תוכן `supabase_schema.sql`
3. לחץ **Run** (Ctrl+Enter)
4. תראה "Success"

### 2. הגדרת Auth
Supabase → Authentication → Settings:
- **Email Confirm**: OFF (לפיתוח) / ON (לפרודקשן)
- **Site URL**: כתובת Netlify שלך (אחרי העלאה)

## 👑 איך יוצרים משתמש Admin

### שלב 1: הירשם לאתר
הירשם עם האימייל שלך דרך האתר עצמו.

### שלב 2: שנה role ל-admin ב-Supabase
**אפשרות א — דרך Table Editor:**
1. Supabase → Table Editor → טבלת `profiles`
2. מצא את השורה שלך לפי האימייל
3. לחץ על שדה `role`
4. שנה מ-`user` ל-`admin`
5. לחץ **Save**

**אפשרות ב — דרך SQL Editor:**
```sql
UPDATE profiles
SET role = 'admin'
WHERE id = (
  SELECT id FROM auth.users WHERE email = 'האימייל-שלך@example.com'
);
```

### שלב 3: כניסה מחדש
התנתק והתחבר מחדש → יופיע כפתור ⚙️ **ניהול** בניווט.

## 🧪 בדיקות שלב אחרי שלב

### בדיקה 1: הרשמה
1. פתח את האתר
2. לחץ "הרשמה"
3. מלא שם, שם משפחה, טלפון, אימייל, סיסמה (8+ תווים)
4. לחץ "הרשמה"
5. **ציפייה**: עובר לדשבורד אוטומטית (אם Email Confirm=OFF)
6. **בדיקה ב-Supabase**: Table Editor → `profiles` — אמור להיות שורה חדשה

### בדיקה 2: התחברות
1. לחץ "יציאה"
2. לחץ "כניסה"
3. הכנס אימייל + סיסמה
4. **ציפייה**: עובר לדשבורד עם "ברוכים הבאים"

### בדיקה 3: יצירת כרטיס
1. לחץ "יצירת כרטיס" בניווט
2. מלא את כל שלבי הטופס (4 שלבים)
3. לחץ "סיים"
4. **ציפייה**: מופיע "הכרטיס נשמר לחשבון שלך"
5. **בדיקה ב-Supabase**: Table Editor → `shidduch_cards` — אמור להיות שורה חדשה

### בדיקה 4: עריכת כרטיס
1. עבור לדשבורד
2. לחץ ✏️ על כרטיס קיים
3. שנה שדה כלשהו
4. עבור לשלב 4 ולחץ "סיים"
5. **ציפייה**: הכרטיס מתעדכן (גם ב-Supabase)

### בדיקה 5: רענון דף
1. רענן את הדף (F5)
2. **ציפייה**: עדיין מחובר, מחזיר לאותו דף

### בדיקה 6: כניסה ממכשיר אחר
1. פתח את האתר ממכשיר/דפדפן אחר
2. התחבר עם אותו חשבון
3. **ציפייה**: הכרטיסים מופיעים

### בדיקה 7: חסימה
1. כנס ל-admin
2. לחץ "ניהול" → "חסימת משתמשים"
3. הכנס טלפון/אימייל של משתמש
4. לחץ "חסום משתמש"
5. נסה להתחבר עם אותו אימייל
6. **ציפייה**: הודעת חסימה

### בדיקה 8: Admin
1. וודא שה-role שלך = admin (ראה למעלה)
2. התחבר מחדש
3. **ציפייה**: רואה כפתור "⚙️ ניהול" בניווט
4. לחץ עליו
5. **ציפייה**: נכנס לדף הניהול
